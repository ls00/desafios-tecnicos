# Desafios Técnicos

Repositório para reunir desafios técnicos, cada um organizado em sua própria pasta. O código, as instruções e o README de cada desafio permanecem junto ao respectivo projeto.

## Desafios

- [BTG Pactual](btg-pactual/README.md): processamento e consulta de pedidos com RabbitMQ, MongoDB e API REST.
- [Itaú Unibanco](itau-backend/README.md): API REST em memória para receber transações e calcular estatísticas.

## Estrutura

```text
.
├── btg-pactual/
│   └── README.md
└── itau-backend/
    └── README.md
```

Novos desafios devem ser adicionados em uma nova pasta na raiz, com sua documentação e arquivos específicos.
